\section{Marked-Context Metatheory}
\label{supp:marked}

Marked context typing (introduced in the Error Marking section of the main
paper) is validated by a pair of theorems mirroring the unmarked plug totality and
soundness theorems.

\begin{theorem}[Marked Plug Decomposition -- Totality]\label{supp:thm:mplug-decompose}
For any context $\C$, expression $e$, and outer derivation mode $d$:
\begin{itemize}
\item If\/ $\synmark{\C[e]}{\chk{e_\star}}{\tau}$, then there exist $\Delta'$, $\Gamma'$, $\chk\C$, $\chk e$, and $m$ such that $\mctxclass{\C}{\chk\C}{\synmode\;\tau}{\Delta';\,\Gamma'}{m}$, $e$ marks to $\chk e$ at focus mode $m$, and $\chk{e_\star} = \chk\C[\chk e]$.
\item If\/ $\anamark{\C[e]}{\chk{e_\star}}{\tau}$, then there exist $\Delta'$, $\Gamma'$, $\chk\C$, $\chk e$, and $m$ such that $\mctxclass{\C}{\chk\C}{\anamode\;\tau}{\Delta';\,\Gamma'}{m}$, $e$ marks to $\chk e$ at focus mode $m$, and $\chk{e_\star} = \chk\C[\chk e]$.
\end{itemize}
Here ``$e$ marks to $\chk e$ at focus mode $m$'' means: if $m = \synmode\;\tau'$ then $\synmark[\Delta';\,\Gamma']{e}{\chk e}{\tau'}$; if $m = \anamode\;\tau'$ then $\anamark[\Delta';\,\Gamma']{e}{\chk e}{\tau'}$.
\end{theorem}

\begin{theorem}[Marked Plug Composition -- Soundness]\label{supp:thm:mplug-compose}
For any context $\C$, marked context $\chk\C$, outer derivation mode $d$, and focus mode $m$: if\/ $\mctxclass{\C}{\chk\C}{d}{\Delta';\,\Gamma'}{m}$ and $e$ marks to $\chk e$ at focus mode $m$, then $\C[e]$ marks to $\chk\C[\chk e]$ at outer derivation mode $d$.
\end{theorem}
